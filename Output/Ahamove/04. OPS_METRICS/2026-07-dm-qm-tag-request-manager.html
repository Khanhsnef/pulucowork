⚡ Hướng Dẫn Tải Apps Script Để Liên Kết Google Sheet

Anh/chị chỉ cần thực hiện 3 bước đơn giản sau để liên kết trang HTML này trực tiếp tới Google Sheet Target của anh/chị:

  1. Mở file Google Sheet target: Link Google Sheet 1tsoIAE...
  2. Vào menu Tiện ích mở rộng (Extensions) $\rightarrow$ Apps Script.
  3. Xóa sạch code cũ và dán toàn bộ đoạn code Apps Script bên dưới vào, sau đó nhấn Triển khai (Deploy) $\rightarrow$ Triển khai dưới dạng ứng dụng web (New Deployment as Web App).
  4. Chọn quyền truy cập: "Bất kỳ ai" (Anyone) $\rightarrow$ Nhấn Triển khai (Deploy) và sao chép Web App URL dán vào ô "Kích hoạt đồng bộ" phía trên!
