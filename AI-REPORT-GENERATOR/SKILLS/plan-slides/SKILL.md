# Plan Slides Skill

## Purpose
Assigns each storyline topic to 1 of 7 Master Executive 16:9 Templates in `TEMPLATES/`:
1. `executive-summary` (Hero KPI & Key Takeaways)
2. `kpi-dashboard` (Ops Health Matrix)
3. `comparison` (Benchmark / Before-After)
4. `trend` (Growth & Time-series)
5. `cause-effect` (Diagnostic Fishbone/Matrix)
6. `timeline` (4-Step Process / Project Roadmap)
7. `action-plan` (Initiatives & SLA Table)

## Input
- `Storyline` (JSON)

## Output
- `ReportPlan` (JSON)
