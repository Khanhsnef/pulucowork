# Render Slides Skill

## Purpose
Invokes `TOOLS/renderer/render_html.py` to produce a standalone 16:9 HTML slide deck.

## Features
- **Live Edit Mode**: Press key `E` or click `✏️ Edit Mode` to edit numbers and text on browser live.
- **Responsive 16:9 Canvas**: Auto-scales to any screen width while preserving 1920x1080 proportion.
- **Export Ready**: Includes print-to-pdf styling.

## Output
- `OUTPUT/<report_name>/report.html`
