# Export Report Skill

## Purpose
Runs final export pipelines to build native editable PowerPoint decks (`.pptx`) using `TOOLS/pptx-exporter/export_pptx.py` and static PDF/PNG assets.

## Deliverables
- `report.html` (Live Edit HTML presentation)
- `report-editable.pptx` (PowerPoint 16:9 native editable shapes & text)
- `report.pdf` (Print-ready PDF)
- `slides/*.png` (1920x1080 slide images)
