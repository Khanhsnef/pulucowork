## Core Frameworks & Mental Models

### 1. The 6-Step Storytelling with Data Process
1. **Understand the Context** — Define the Who, What, and How before touching data.
2. **Choose an Appropriate Display** — Select the right visual format for your message (12 core types).
3. **Eliminate Clutter** — Remove cognitive burden using Gestalt principles.
4. **Focus Your Audience's Attention** — Leverage preattentive attributes (color, size, position) to direct the eye.
5. **Think Like a Designer** — Apply affordances, accessibility, aesthetics, and acceptance.
6. **Tell a Story** — Craft a clear narrative arc (Beginning, Conflict, Resolution).

### 2. Context Triad & The Big Idea
- **WHO**: Specific decision-maker audience. Never communicate to "a general audience."
- **WHAT**: The exact action you need the audience to take. (Explanatory, not exploratory).
- **HOW**: The data and visual mechanism used to illustrate the point.
- **The 3-Minute Story**: If you only had 3 minutes, what would you say?
- **The Big Idea**: A single sentence containing (1) your point of view, (2) what is at stake, and (3) a clear call to action.

### 3. Visual Display Choice Rule
- **Simple Text**: Use when you have 1 or 2 numbers to report. Don't use a chart for a single number.
- **Tables**: Use when communicating to a multi-level audience or requiring precise value lookup.
- **Heatmaps**: Enhance tables with color intensity to guide visual scanning without reading every cell.
- **Line Graphs**: Best for continuous data (time series).
- **Slopegraphs**: Ideal for comparing two time points across multiple categories.
- **Bar Charts**: Best for categorical data. Must always start y-axis at 0.
- **Horizontal Bar Charts**: Best for long category names.

### 4. Anti-Patterns (Golden Rules of Avoidance)
- 🚫 **Never use 3D**: Adds visual distortion, false depth, and misleads size comparison.
- 🚫 **Never use Pie or Donut Charts**: Human perception cannot accurately compare 2D angles/arc areas. Replace with bar charts.
- 🚫 **Never use Dual Y-Axes**: Confuses viewers on which series maps to which axis. Instead, label data directly or split into 2 stacked panels.
