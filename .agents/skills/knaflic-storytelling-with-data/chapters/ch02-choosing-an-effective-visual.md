# Chapter 2: Choosing an Effective Visual

## Core Idea
Select the visual display that best enables your audience to process the data with minimal cognitive effort. Out of dozens of visual formats, 12 core types cover 80%+ of business needs.

## Frameworks Introduced
- **The 12 Core Visual Types**:
  1. **Simple Text**: Use when you have 1-2 key numbers. Make the number huge with a clear label.
  2. **Table**: Best for multi-level lookups or audiences needing precise values.
  3. **Heatmap**: Table overlaid with color intensity to direct scanning.
  4. **Scatterplot**: Shows relationship between two continuous variables.
  5. **Line Graph**: Best for continuous time-series data.
  6. **Slopegraph**: Compares 2 time points or categories across multiple metrics.
  7. **Vertical Bar Chart**: Standard categorical comparison. Must baseline at 0.
  8. **Stacked Vertical Bar**: Shows total and sub-component breakdown.
  9. **Waterfall Chart**: Displays incremental additions/subtractions to a starting baseline.
  10. **Horizontal Bar Chart**: Best for long category labels (reads left-to-right).
  11. **Stacked Horizontal Bar**: Best for survey results (e.g. Strongly Disagree to Strongly Agree).
  12. **Square Area**: Used only for vast magnitude differences.

## Anti-patterns
- **Pie & Donut Charts**: Avoid completely. Human eyes cannot compare 2D arc angles or slice areas accurately.
- **3D Charts**: Never use 3D. Distorts perception and adds fake depth.
- **Secondary Y-Axes**: Confuses viewers. Use direct labeling on data lines or split into 2 aligned vertical charts.

## Decision Rules
- If reporting 1-2 numbers → Use **Simple Text**.
- If category labels are long → Use **Horizontal Bar Chart**.
- If showing progress/change across 2 time points → Use **Slopegraph**.
- If showing time series → Use **Line Graph**.
