# Chapter 5: Think Like a Designer

## Core Idea
Apply fundamental design concepts—affordances, accessibility, aesthetics, and acceptance—to transform raw charts into intuitive, professional visual experiences.

## Frameworks Introduced
- **Affordances**: Visual cues indicating how an element should be interpreted:
  - *Highlight important things* (Bold, Accent color).
  - *Eliminate distractions* (Remove non-critical data).
  - *Create visual hierarchy* (Font sizes, placement order).
- **Accessibility**: Design for diverse technical literacy and visual abilities:
  - Keep text legible and avoid jargon.
  - Don't rely solely on color (use text labels + color).
  - Use high contrast between text and background.
- **Aesthetics**: Beautiful design increases audience trust and engagement:
  - Intentional white space.
  - Consistent typography and left-aligned text.
  - Harmonious color palette (avoid default bright software colors).
- **Acceptance**: Overcoming audience resistance to new formats:
  - Build familiarity before introducing novel visuals.
  - Show side-by-side comparisons when introducing changes.
