# Cheatsheet & Decision Rules — Storytelling with Data

## Visual Display Selection Matrix

| Data / Goal | Recommended Visual | Why |
| :--- | :--- | :--- |
| **1-2 Numbers** | Simple Text Callout | Big number + label beats unnecessary chart |
| **Lookup Values** | Table or Heatmap | Easy cell lookup; heatmap guides eye |
| **Time Series** | Line Graph | Continuous left-to-right flow |
| **2 Time Points** | Slopegraph | Shows magnitude and direction of change |
| **Categories** | Vertical Bar Chart | Y-axis must start at 0 |
| **Long Label Names**| Horizontal Bar Chart | Left-to-right reading without tilted text |
| **Part-to-Whole** | Stacked Horizontal Bar| Replaces pie charts for survey response |

## Gestalt Principles Quick Summary

| Principle | Meaning & Application |
| :--- | :--- |
| **Proximity** | Place related labels close to data points |
| **Similarity** | Use same color for related category metrics |
| **Enclosure** | Shading background box behind key area |
| **Closure** | Remove unnecessary chart border lines |
| **Continuity** | Align text and chart elements left-to-right |
| **Connection** | Connect data points with line to show trend |

## Preattentive Attributes Checklist

- **Color**: Accent hue for focus, gray for background.
- **Size**: Large font size for key metric numbers.
- **Position**: Top-left position for highest priority message.
- **Text Weight**: **Bold** for key action words.

## Anti-Pattern Red Lines

- 🚫 **NO 3D Charts**
- 🚫 **NO Pie or Donut Charts**
- 🚫 **NO Secondary Y-Axes**
- 🚫 **NO Unsorted Bar Charts** (Sort descending unless chronological)
