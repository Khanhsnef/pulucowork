# Glossary — Storytelling with Data

**Affordances** — Visual cues built into design that signal to the user how to interact with or interpret elements (Ch 05).

**Big Idea** — A single sentence containing a unique point of view, what is at stake, and a clear call to action (Ch 01).

**Clutter** — Visual elements in a chart that take up space but do not increase understanding, increasing cognitive load (Ch 03).

**Cognitive Load** — The total mental effort being used in the working memory by an audience to interpret a message (Ch 03).

**Decluttering** — The process of stripping away non-essential gridlines, borders, backgrounds, and markers to highlight signal over noise (Ch 03).

**Exploratory Analysis** — The process of analyzing data to discover insights or test hypotheses (hunting for pearls) (Ch 01).

**Explanatory Analysis** — Communicating specific insights and recommendations to an audience (showing the pearls) (Ch 01).

**Freytag's Pyramid** — A framework for narrative structure consisting of Beginning/Plot, Rising Action, Climax, Falling Action, and Resolution (Ch 07).

**Gestalt Principles** — Principles of visual perception defining how humans group similar elements, recognize patterns, and simplify complex images (Ch 03).

**Heatmap** — A tabular visual using color shading to represent relative data values across cells (Ch 02).

**Horizontal Logic** — Structural principle where slide titles alone form a complete, coherent narrative when read sequentially (Ch 07).

**Iconic Memory** — Subconscious, super-fast visual memory processing preattentive attributes in less than a second (Ch 04).

**Preattentive Attributes** — Visual features (color, size, position, shape) processed by iconic memory before conscious attention (Ch 04).

**Slopegraph** — A chart type connecting two time points or categories with straight lines to show relative change (Ch 02).

**Spaghetti Graph** — A line chart with too many overlapping lines that creates visual confusion (Ch 09).

**Storyboard** — A low-fidelity visual outline or sequence of cards planning the narrative structure before design (Ch 01).

**Vertical Logic** — Structural principle where content on a given slide directly supports its title header (Ch 07).
